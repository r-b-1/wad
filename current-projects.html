AI Desktop Chat

Native desktop assistant focused on screen awareness, OCR, and response speed.

Rust React SSE OCR
  • Built a native macOS app in Tauri with OCR via the macOS Vision framework and question detection that dispatches to GPT-4o mini in under a second.
  • Implemented perceptual hashing on a 400ms Tokio loop so unchanged frames are skipped and continuous watch sessions stay efficient.
  • Engineered streaming responses over SSE with exponential backoff and jitter retry for 429 and 5xx failures, plus inline URL citations for live web results.
  • Integrated Supabase auth and persisted multi-session chat history with create, rename, and delete flows.
